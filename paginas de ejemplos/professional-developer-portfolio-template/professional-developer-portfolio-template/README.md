# Professional Developer Portfolio Template

A Pen created on CodePen.

Original URL: [https://codepen.io/Dharuneyyyyyy/pen/pvEjPZo](https://codepen.io/Dharuneyyyyyy/pen/pvEjPZo).

🚀 A production-grade, Awwwards-inspired developer portfolio built entirely with HTML5, 
Tailwind CSS, GSAP (GreenSock Animation Platform), and vanilla JavaScript — no frameworks, 
no build tools, just raw front-end mastery.

This portfolio template features:
✦ Custom </> code-icon cursor (desktop only, auto-hidden on mobile)
✦ GSAP ScrollTrigger scroll-reveal animations
✦ Kinetic hero typography with overflow-clip line reveals
✦ Animated page loader with live counter
✦ Asymmetric masonry gallery with category filter system
✦ Project list with floating image preview on hover
✦ GitHub REST API integration with live stats
✦ Contribution heatmap grid (auto-generated)
✦ Animated stats counter (Intersection Observer + GSAP)
✦ Contact form with submit state animation
✦ Noise texture overlay, editorial grid background
✦ Fully responsive — mobile-first layout
✦ Light theme: ivory/cream + charcoal + cobalt blue

💡 Tech Stack: HTML5 · Tailwind CSS (CDN) · GSAP 3.12 · ScrollTrigger · Vanilla JS · GitHub API

🎨 Font Stack: Syne (display) · Fraunces (serif italic) · DM Mono (code/UI)

🏆 Designed to meet Awwwards, CSS Design Awards, and Dribbble quality standards.
